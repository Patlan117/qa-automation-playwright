\# Mis apuntes de Git



\## Comandos aprendidos



\- git init: Crea un nuevo repositorio

\- git status: Muestra el estatus del repositorio

\- git add: Prepara los cambios

\- git commit: Registra los cambios en el historial

\- git log: Muestra el historial

\- git branch: Muestra la rama en que se esta trabajando

\- git switch: Cambia de rama



\## Diferencia entre Git y GitHub



Mi explicación:

Git es un software para la gestión de versiones.

GitHub es un servicio para almacenar los repositorios en la nube y trabajar en conjunto con más personas.
